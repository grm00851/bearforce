# BEARFORCE — бесплатная PWA-версия

В архиве:
- `index.html` — финальная версия BEARFORCE v69;
- `manifest.webmanifest` — параметры установки на экран «Домой»;
- `service-worker.js` — кэширование для повторного запуска офлайн;
- `icon-192.png` и `icon-512.png` — значки приложения.

## Важно
Чтобы iPhone мог установить приложение как PWA по ссылке, эти файлы нужно разместить на HTTPS-хостинге. Просто открыть HTML из «Файлов» недостаточно для полноценной установки PWA и работы service worker.

## После размещения на HTTPS
1. Открой опубликованную ссылку в Safari на iPhone.
2. Нажми «Поделиться».
3. Выбери «На экран Домой».
4. Если доступен переключатель «Открывать как веб-приложение», включи его.
5. Нажми «Добавить».

Не загружай сюда личные данные. Сначала проверь приложение после установки, особенно сохранение тренировок и дневника.


BEARFORCE v70 — добавлены категории «Трапеции» и «Шея», 10 упражнений, программы с поэтапной прогрессией на 6 и 4 недели. Упражнения для шеи представлены только в мягком изометрическом/контрольном формате без мостиков и утяжелителей.

Почта, Google OAuth и SMS-подтверждение не включены: для реальной привязки аккаунтов нужна серверная часть, OAuth credentials и SMS-провайдер. Не вводите секретные ключи в index.html.
